# Schema

The persisted artifact format is versioned. The current schema contract is kept
as a repository document so it can be cited directly and reviewed deliberately.

Use the schema when you need to understand:

- what fields a captured artifact contains;
- how fingerprints and provenance are represented;
- what offline tools such as `cargo-vvm` expect to merge.

Direct schema link: [`docs/coverage-json-v1.md`](../../../coverage-json-v1.md)
